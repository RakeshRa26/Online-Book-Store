# 📚 Online Book Store

A web-based Online Book Store built with PHP, CSS, JavaScript, and a database to provide a convenient way for users to explore books, manage their shopping cart, and place orders.

**Developed by Rakesh Rawal**

[View Repository](https://github.com/RakeshRa26/Online-Book-Store)

## 📌 About the Project

The Online Book Store is a web development project designed to demonstrate the fundamentals of building a dynamic e-commerce website. It provides a platform where users can browse available books, search for products, register or log in, and manage their shopping activities.

The project also includes an administration area for managing products, users, orders, and customer messages.

## ⚙️ Installation and Setup

### Prerequisites

- A computer running Windows, macOS, or Linux
- PHP
- MySQL or MariaDB, if required by the application
- XAMPP or another compatible local server
- A web browser

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/RakeshRa26/Online-Book-Store.git
```

### Step 2: Move the Project

For XAMPP on Windows, place the project folder inside:

```text
C:\xampp\htdocs\Online-Book-Store
```

### Step 3: Start the Local Server

Open the XAMPP Control Panel and start Apache and MySQL.

### Step 4: Configure the Database

1. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
2. Create the database required by the project.
3. Import the project's database SQL file, if available.
4. Open `config.php` and configure the database host, username, password, and database name.

Use the actual database name and schema expected by your source code.

### Step 5: Run the Website

Open the following URL in your browser:

```text
http://localhost/Online-Book-Store/
```

If the project uses a different entry page or database configuration, adjust the setup accordingly.
